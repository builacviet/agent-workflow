# Task handoff — current entry point

For a **new authorized task**, use the short [handoff template](templates/handoff.md). Record exact base/head SHAs, changed paths, actual tests and outcomes, security boundaries, blockers and independent review status.

**Historical handoffs were moved without deleting the original record** to [the archived handoff log](history/handoff-log.md). It retains the old Phase 1/2/3.1 reports for audits and dated evidence, but must **not** be read wholesale by every agent at startup.

See [`AGENTS.md`](../AGENTS.md), [documentation index](INDEX.md) and [review policy](review-policy.md). A past handoff is not proof of the current running system or a current Owner approval.
