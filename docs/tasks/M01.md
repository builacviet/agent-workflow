## Acceptance criteria

1. **AC01 — Provenance:** Cite exact CURRENT code/line symbols and merged CL-12 TARGET decisions at pinned baseline. Label each statement SOURCE FACT, TARGET PROPOSAL, HISTORICAL or UNKNOWN when meaningfully disputed. No production or native-Linux proof inferred.
2. **AC02 — Authority and identity:** Define owners of WFC/dispatch/Executor/remote truth, immutable task/round/input/dispatch/stage/engine/artifact identity and no-cross-system-atomicity limitation.
3. **AC03 — Lifecycle contract:** Specify durable write-before-effect ordering, stage create/stop/unknown handling, container ownership proof, idempotency and the blocked fence. Wrong ID/DB/engine or late create must never imply safe name-based cleanup.
4. **AC04 — Publish reconciliation:** Specify intended commit/parent/branch, expected ref, Draft PR identity/policy, expected artifact/test evidence, independent read-only verification, lost push/POST/PATCH response and no automatic replay or force-push.
5. **AC05 — WFC coordination:** Define manual/automated authorization fence, publish precondition, automated single local transaction for `DONE` plus `READY_IN_REVIEW` only after verified remote receipt and settled stage. Preserve manual-only paths, exact-SHA/two-round review and already-progressed historical reviews.
6. **AC06 — Recovery matrix:** Distinct outcome/evidence/disposition for published+handoff, published-no-handoff, verified no-effect, unknown/conflicting, revoke failure and post-handoff cleanup failure. Owner/operator gate and immutable evidence required before slot release; no unimplemented operator command represented as CURRENT.
7. **AC07 — Test contract:** Trace all major crash/uncertain-side-effect boundaries to deterministic M02 fixture/negative tests including no destructive call on unowned ID, late create, lost responses, concurrent manual handoff and split local writes. **M01 test execution NOT RUN.**
8. **AC08 — Decision register:** Explicitly list D-01/D-02/D-03 proposed defaults and unresolved choices, schema/authority/migration dependencies, and separate acceptance/cutover gates. Owner approval required before contract status changes to accepted.
9. **AC09 — Review integrity:** Verify actual PR base, HEAD, exactly these two changed paths and local Markdown relative links; independent reviewer checks the complete spec/source truth at exact head. Maximum 2 review rounds; Owner alone merges or signs off.
