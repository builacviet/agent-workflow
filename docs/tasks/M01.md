## Acceptance criteria

1. **AC01 — Provenance:** Cite exact CURRENT code/line symbols and merged CL-12 TARGET decisions at pinned baseline. Label each statement SOURCE FACT, TARGET PROPOSAL, HISTORICAL or UNKNOWN when meaningfully disputed. No production or native-Linux proof inferred.
2. **AC02 — Authority and identity:** Define owners of WFC/dispatch/Executor/remote truth, immutable task/round/input/dispatch/stage/engine/artifact identity and no-cross-system-atomicity limitation.
3. **AC03 — Lifecycle contract:** Specify **per-stage** durable create intent → immutable handle persisted → start intent → stage result → stop/reap intent → verified settlement **before next stage**, with independent Controller/Executor journaling, late-command proof and fenced unknown. Wrong ID/DB/engine or late create must never imply safe name-based cleanup.
4. **AC04 — Publish reconciliation:** Specify independent durable intent and authorization fence for **each** push/POST/PATCH, expected commit/parent/ref, stable PR identity/head/base/repo/actor/body, validated receipt, partial stale PR state, mutation-in-flight expiry/override, verified-no-effect proof and lost response; never blindly repeat or force-push.
5. **AC05 — WFC coordination:** Require one verified physical SQLite DB and **same serialized writer arbitration** for manual handoff and auto admission; distinct manual authority. Automated single local transaction for receipt/finalization ID + `DONE` + `READY_IN_REVIEW` only after verified remote, all stages and credential safety. Specify lost commit acknowledgement read-by-ID and preserve already-progressed reviews, exact SHA and two-round policy.
6. **AC06 — Recovery matrix:** Distinct outcome/evidence/disposition for complete publish+handoff, remote partial, missing handoff, verified no effect, unknown/conflict, **revoke uncertain** and **handoff committed but final cleanup failed**. Require verified-owned stop/reap independent of release; conditional audited disposition+slot release in one exact-dispatch transaction; no unimplemented command represented as CURRENT.
7. **AC07 — Test contract:** For each crash/uncertain boundary specify **CURRENT as-built characterization separately from TARGET expected safety** on both sides of each local commit and external effect: invalid ownership, late create, handle/start/stop/reap loss, stale PR body, lost push/POST/PATCH, both manual/admission races, split local writes and lost finalization commit response. **M01 test execution NOT RUN.**
8. **AC08 — Decision register:** Explicitly list D-01/D-02/D-03 proposed defaults and unresolved choices, **split-ledger/restore authority, late-command evidence, writer/actor/credential gates**, schema/migration dependencies and separate M01 acceptance, PR merge, M02 start, implementation and cutover decisions. Owner approval required before contract status changes to accepted.
9. **AC09 — Review integrity:** Verify actual PR base, HEAD, exactly these two changed paths and local Markdown relative links; independent reviewer checks the complete spec/source truth at exact head. Maximum 2 review rounds; Owner alone merges or signs off.
